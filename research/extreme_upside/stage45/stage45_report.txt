1. Statistical prediction - YES.
   - Inside the frozen high-volatility state (S1-P5), a second-stage model predicts a +100 % move day within
     3 sessions far better than the state rank.
   - PR-AUC 0.141 vs 0.024. Per-day top-10 % precision 7.19 % vs 2.68 % (base 1.49 %; 5,492 signals each).
2. Event detection - YES, robustly.
   - The timing signals catch 210 of 303 eligible E1 events (69.3 %) in the 3 sessions before the move day,
     against 81 / 303 (26.7 %) for the state rank: +42.6 pp, CI [34.5, 49.8].
   - The membership-matched same-security placebo ratio is 4.33.
3. Genuine pre-event timing - WEAK.
   - At the first signal, the captured stock is already a median +65 % above its 10-day low open (71 % ≥ +50 %).
     The model mainly sees a move that has started.
   - Restricted to rows with run-up < 50 %: +21.0 pp [11.0, 31.1], at event precision 2.26 % (state 1.71 %).
4. Capturable price movement - NOT BEYOND THE STATE.
   - One short-list target passes C4: CB5_50, a max close ≥ +50 % within 5 sessions, in 3.74 % of 5,492 signals
     vs 1.73 % base.
   - It is no better than the plain state signals (+0.17 pp [-0.82, 1.13]).
   - All adverse-constrained brackets fail: +30 % before -10 % within 5 sessions succeeds in 12.8 %; the -10 %
     limit comes first in 57.3 %.
5. Hypothetical execution / profitability - NO.
   - From the next open, signals lose a median 3.4 % in 5 sessions and 5.4 % in 10; 42 % touch -20 % within 10
     sessions.
   - The bracket payoff proxy is -0.56 % before costs.
   - With the measured quoted spread (s30 = 0.95 %) it is -1.61 % (optimistic), -2.96 % [-3.52, -2.43]
     (neutral) and -4.91 % (conservative).
   - Identical to the whole conditional population.


=====================================================================================================================
DESIGN IN ONE SCREEN
=====================================================================================================================
- State (frozen, never retrained): the Stage 3 full-A RF score, ranked daily inside the universe.
  - Primary population S1-P5: price ≥ $1, trailing 20-session median dollar volume ≥ $500k, top 5 % of the
    state rank.
  - Rows within 10 sessions after a move day are excluded ex ante.
- Event onset (move day): first session whose HIGH reaches +100 % from the reference open (E1). E2, E3, B10 and
  B-max10 are alternatives.
- Target ONSET_3 = 1 if a move day falls in t+1..t+3. Primary timing model: L2 logistic regression on 39
  features (volatility acceleration, volume acceleration, path / compression, state transitions).
- Training starts 2017; hyperparameters are chosen on 2020 only.
- Rolling-origin folds with a 60-day purge:
  - a: train to 2020, test 2021-22;
  - b: train to 2022, test 2023-25;
  - c: train to 2025, test 2026 YTD.
- Signals = per-day top 10 % of the population, for the timing model and the state rank alike (same count).
- Statistics:
  - paired event-level comparisons on identical eligible events;
  - security-cluster and two-way (security x date) bootstrap, 2,000 resamples;
  - BH within target families.

ANSWERS TO THE TWELVE QUESTIONS
=====================================================================================================================
Q1. Does the Stage 3 high-volatility state contain additional short-term timing information?
    YES, mostly through information about a move already in progress. A smaller genuine pre-move part exists.

    Model (S1-P5, test 2021-25, valid rows 49,651, positives 740, base 1.49 %; 5,492 signals per model):

    | Model | PR-AUC | Per-day top-10 % precision | Lift | Pre-event capture / 303 eligible |
    |---|---|---|---|---|
    | STATE (frozen RF rank) | 0.024 | 2.68 % | 1.80 | 81 (26.7 %) |
    | L2 FULL (primary) | 0.141 | 7.19 % | 4.83 | 210 (69.3 %) |
    | RF FULL | 0.165 | 7.43 % | 4.98 | 215 (71.0 %) |
    | LR STATE + volatility accel. | 0.059 | 4.72 % | 3.16 | 192 (63.4 %) |
    | LR STATE + volume accel. | 0.080 | 5.54 % | 3.71 | 190 (62.7 %) |
    | LR STATE + path / compression | 0.131 | 6.92 % | 4.64 | 201 (66.3 %) |
    | LR transitions only | 0.028 | 2.75 % | 1.84 | 81 (26.7 %) |

    - Most of the information is in the path features. The strongest univariate features (training window) are
      distance from the 20-day low (AUC 0.81), 3-day volatility (0.73), last-day move (0.73) and 1- / 3-day
      return (0.71).
    - State-transition features (entering P5, run length, percentile change) carry almost none.

Q2. Can the onset of an extreme move be predicted within 1-3 sessions?

    YES on every prediction and detection metric. NO on capturable outcomes.

      - Leave-one-group-out: +41.3 to +42.2 pp.
    - PR-AUC: +0.118 [0.094, 0.146].
    - Full vs volatility-only: +5.9 pp [-0.7, 12.4]. Full vs volume-only: +6.6 pp [0.3, 12.9]. Full vs RF:
      -1.7 pp [-5.6, 2.4].

Q11. Is there sufficient evidence to begin Stage 5?
     NO. Decision C.
     - C7 (cost) and C5 (downside) fail.
     - The one passing capturable target (C4) shows no gain over the plain state.
     - The timing gain (C2, C3) is mostly detection of moves already under way.
     - A PASS on prediction and detection alone does not justify a trading simulation (protocol and brief).

Q12. If not, what exact unresolved hypothesis should be tested next?
     H-next (intraday confirmation, pre-registered before any look at intraday outcomes):

       Among S1-P5 rows with a frozen L2 timing signal at the close of t (5,492 rows in 2021-25), an entry on
       day t+1 ONLY IF the stock trades above the day-t high within the first 30 minutes, with first-30-min
       dollar volume ≥ $1M, has a positive mean payoff after the NEUTRAL cost (2.40 %). The payoff is the same
       bracket as here: +30 % / -10 % / close t+5, from the trigger price.

     How to test:
     - in QC, on minute bars of all signal days (EXEC needed about 0.5 s per day, so about 45 minutes);
     - against the same rule on STATE signals and on random population rows;
     - 2021-25 as historical replication, then a prospective shadow log after 2026-08-27.

     Rationale:
     - The daily data show the signals are right about which stocks move, but entering at the next open buys
       into mean reversion: median -3.4 % at t+5; the adverse limit comes first 57 % of the time.
     - Only an entry conditioned on same-day continuation could separate the 13 % successes from the 57 %
       adverse cases. Ex ante, with daily data, they look identical.
     - If this fails, the extreme-upside line should be closed for long trading.

     The short side (selected stocks drift down) is a separate hypothesis. It needs borrow availability and
     fees, which are not in the data; it is not proposed here.
